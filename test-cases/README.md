# 🧪 Urban Routes – Testing Manual

## 📄 Descripción del Proyecto
Este proyecto consiste en la ejecución de **testing manual** para la aplicación web **Urban Routes**, una plataforma de transporte. El objetivo principal fue validar el correcto funcionamiento de las funcionalidades, asegurar el cumplimiento de los requisitos y garantizar una experiencia de usuario estable y confiable.

El proyecto fue desarrollado como parte de mi formación como **QA Tester en el Bootcamp de TripleTen**.

---

## 🎯 Objetivos
- Analizar y comprender los requisitos funcionales del sistema
- Diseñar y ejecutar casos de prueba manuales
- Identificar, documentar y reportar defectos
- Validar el comportamiento del sistema desde la perspectiva del usuario final

---

## 🛠️ Herramientas y Tecnologías
- Jira (gestión y reporte de bugs)
- Chrome DevTools
- Google Chrome
- Técnicas de testing manual
- Documentación en Markdown y Excel

---

## 🧪 Tipos de Pruebas Realizadas
- Testing funcional
- Testing exploratorio
- Análisis de requisitos
- Pruebas basadas en:
  - Partición de equivalencia
  - Análisis de valores límite
